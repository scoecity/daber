# Daber (דַּבֵּר)

A gamified web app for learning to read and speak everyday Hebrew: the alef-bet, vowel marks, conversation phrases, flashcards, tests and "repeat after me" speaking practice.

Live at https://scoecity.github.io/daber/ — open it on your phone and use Add to Home Screen.

Everything is in `index.html`; progress is saved on the device.
